07 · Metodologia DISC — Base Teórica

A ciência por trás da Camada 1

Texto que vai nas páginas 03–04 do relatório. É o ponto de partida para qualquer avaliado — a teoria antes dos resultados.

Texto para Pg 04 do relatório (Metodologia DISC): A busca por compreender por que as pessoas pensam, sentem e agem de maneiras diferentes acompanha os estudos sobre o comportamento humano há séculos. Foi nesse contexto que William Moulton Marston, psicólogo formado em Harvard, apresentou importantes contribuições para o estudo do comportamento humano. Em 1928, publicou a obra "Emotions of Normal People", na qual apresentou uma teoria para compreender como as pessoas respondem emocionalmente às situações e às influências do ambiente. Os estudos de Marston se tornaram a principal base conceitual do que posteriormente ficou conhecido como DISC — um modelo amplamente utilizado para compreender tendências comportamentais e diferentes formas de agir, comunicar, decidir e interagir. A teoria considera quatro grandes dimensões comportamentais: Dominância, Influência, Estabilidade e Conformidade. Cada pessoa apresenta essas quatro dimensões em diferentes níveis de intensidade. Por isso, o DISC não deve ser utilizado para colocar pessoas em caixas, mas como ferramenta para identificar tendências, preferências e padrões de comportamento.

08 · Os 4 Fatores DISC — Base Completa

A base que alimenta os prompts da IA

Esta base alimenta os prompts da IA e é usada para gerar os textos estáticos do relatório. Cada perfil tem sua descrição completa, pontos fortes, desafios, motivadores e medos.

D
Dominância
Rápido · Ousado · Orientado a resultados

O Dominante vive para desafios. Para ele, inércia é desperdício. Age primeiro, analisa depois. Tem energia natural de comando que emerge mesmo sem cargo de liderança.

  • Forças:
  • · Decisão rápida mesmo sob pressão
  • · Mobiliza pessoas e recursos com velocidade
  • · Coragem para decisões impopulares
  • · Resiliência diante de obstáculos
  • · Foco absoluto no resultado
  • Medos:
  • · Falhar e perder autoridade pública
  • · Perder autonomia e liberdade
  • · Ser microgerenciado
  • · Ambientes sem metas ou urgência
  • Motiva:
  • · Poder, autonomia, desafios novos
  • · Reconhecimento por resultados concretos
  • · Competição e oportunidade de superar limites
I
Influência
Comunicativo · Amigável · Orientado para pessoas

O Influente transforma o ambiente que entra. Não é só extroversão — é a capacidade genuína de fazer as pessoas se sentirem vistas e valorizadas. Cria conexões com facilidade.

  • Forças:
  • · Comunicação poderosa e inspiradora
  • · Facilidade de criar conexões humanas
  • · Energia e clima positivo no ambiente
  • · Criatividade e geração de ideias
  • · Adaptabilidade social
  • Medos:
  • · Rejeição social e perda de aprovação
  • · Ambientes frios e sem interação
  • · Ser ignorado ou não reconhecido
  • · Conflitos que possam romper relações
  • Motiva:
  • · Reconhecimento público e aprovação
  • · Projetos criativos com muita interação
  • · Ambientes dinâmicos com novidade
S
Estabilidade
Paciente · Conciliador · Orientado ao equilíbrio

O Estável é o que mantém tudo em pé enquanto os outros correm. Paciência que parece infinita, lealdade que raramente falha. Não é o mais rápido nem o mais barulhento, mas é o mais confiável.

  • Forças:
  • · Confiabilidade absoluta
  • · Paciência e escuta ativa genuína
  • · Relacionamentos duradouros
  • · Suporte emocional autêntico
  • · Consistência sob alta pressão
  • Medos:
  • · Perda de estabilidade e segurança
  • · Conflitos abertos e tensão constante
  • · Mudanças bruscas sem explicação
  • · Romper relacionamentos importantes
  • Motiva:
  • · Segurança, estabilidade e harmonia
  • · Saber que seu trabalho importa
  • · Equipes coesas e de alta confiança
C
Conformidade
Cauteloso · Detalhista · Orientado à precisão

O Conforme não age sem entender. Para ele, decisão sem dados suficientes é risco desnecessário. Mente analítica que vê o que os outros não veem. Introvertido não por timidez, mas por preferência de profundidade.

  • Forças:
  • · Análise profunda e prevenção de problemas
  • · Precisão e excelência técnica
  • · Planejamento estratégico
  • · Alta capacidade de aprendizado
  • · Pensamento crítico e baseado em dados
  • Medos:
  • · Cometer erros e ser criticado publicamente
  • · Sair das normas estabelecidas
  • · Ambiguidade e falta de clareza
  • · Decidir sem dados suficientes
  • Motiva:
  • · Clareza nas expectativas e critérios
  • · Projetos com alta complexidade técnica
  • · Ser reconhecido pela qualidade

function r1(x) {
  const s = Math.sign(x), a = Math.abs(x)
  return s * Math.round(parseFloat((a * 10).toPrecision(12))) / 10 || 0
}

// /api/assessment/[token]/finalize — usa o motor oficial (porte de motor_referencia.py)
// Arquivo: app/api/assessment/[token]/finalize/route.ts
import INV from '@/data/inventario.json'            // Sec 24 — nunca redigitar os itens
import { pontuarDisc, perfil, indices, lideranca, pontuarJung,
         pontuarValores, zona, validade } from '@/lib/motor'   // porte fiel, testes T1–T8

export async function POST(req: Request, { params }: { params: { token: string } }) {
  const a = await prisma.assessment.findUnique({
    where: { token: params.token }, include: { answers: true }
  })

  // 1. Conferir as 69 telas (16 + 16 + 27 + 10); faltando → 409 com a lista das telas
  // 2. Reconstruir as respostas por etapa: { grupo: { idItem: posição } }
  const posicoes = (etapa: number) => Object.fromEntries(
    a.answers.filter(x => x.etapa === etapa).map(x => [
      Number(x.tela.slice(1)),                                       // "G07" → 7 | "V03" → 3
      Object.fromEntries((x.ordem_final as string[]).map((id, i) => [id, i + 1]))
    ]))

  const nat = pontuarDisc(INV.disc, posicoes(1))     // lança erro se a soma ≠ 200
  const ada = pontuarDisc(INV.disc, posicoes(2))
  const jr = { EI: [], NS: [], TF: [] }
  a.answers.filter(x => x.etapa === 3).forEach(x => jr[x.tela.slice(0, 2)].push(x.resposta_polo_a))
  const jung = pontuarJung(jr)
  const val  = pontuarValores(INV.valores, posicoes(4))     // soma 300

  const pn = perfil(nat.escore, nat.primeiros)
  const pa = perfil(ada.escore, ada.primeiros)
  const ix = indices(nat.escore, ada.escore)
  const vd = validade(a.answers)                            // V1–V6 → confiabilidade

  // 3. Salvar tudo em results (idempotente: upsert por assessment_id)
  const result = await prisma.result.upsert({
    where: { assessment_id: a.id }, update: {},
    create: {
      assessment_id: a.id, versao_instrumento: 'MC-INV 2.2', versao_motor: '2.2.0',
      nat_d: nat.escore.D, nat_i: nat.escore.I, nat_s: nat.escore.S, nat_c: nat.escore.C,
      ada_d: ada.escore.D, ada_i: ada.escore.I, ada_s: ada.escore.S, ada_c: ada.escore.C,
      zonas_nat: mapZona(nat.escore), zonas_ada: mapZona(ada.escore),
      perfil_natural: pn.sigla, perfil_adaptado: pa.sigla,
      variacoes: ix.variacao, indice_adaptacao: ix.indice, classe_adaptacao: ix.classe,
      amplitude_natural: ix.amplitude, fatores_polarizados: ix.polarizados,
      competencias_nat: nat.competencias, competencias_ada: ada.competencias,
      lideranca: lideranca(nat.escore),
      jung_e: jung.pct.E, jung_n: jung.pct.N, jung_t: jung.pct.T, tipo_jung: jung.tipo,
      func_dominante: jung.hier[0], func_auxiliar: jung.hier[1],
      func_terciaria: jung.hier[2], func_inferior: jung.hier[3],
      val_teorico: val.escore.TEO, val_economico: val.escore.ECO, val_estetico: val.escore.EST,
      val_social: val.escore.SOC, val_politico: val.escore.POL, val_principios: val.escore.PRI,
      ranking_valores: val.ranking,
      confiabilidade: vd.confiabilidade, alertas: vd.alertas, tempo_total_s: vd.segundos,
      narrativa_ia: {},
    }
  })

  // 4. Narrativa em fila (Etapa 3). O cálculo acima leva poucos milissegundos.
  await filaNarrativa.add({ resultId: result.id })
  return Response.json({ ok: true, resultId: result.id })
}

Desempenho para aplicação em massa

  • · Cenário de projeto: 700 pessoas no mesmo dia, até 300 ao mesmo tempo, por um link de campanha que gera token individual no primeiro acesso.

  • · O painel numérico aparece na hora. A narrativa da IA entra numa fila com processamento paralelo e limite de chamadas por minuto; o PDF sai quando a fila conclui.

  • · Todo item tem identificador fixo (G07-D, EI04, V03-ECO). Trocar a palavra de um item cria nova versão do instrumento.

  • · Uma aplicação iniciada numa versão termina na mesma versão.
  • · Toda mudança começa em motor_referencia.py, passa pelos testes e só depois vai para o software.

Precisão: o que se garante e o que se conquista

Garantido desde o primeiro dia

A conta. Para a mesma resposta, o resultado é sempre o mesmo e sempre correto em relação à regra. Os testes de ouro provam isso.

Conquistado com dados

A validade: o quanto o escore reflete a pessoa real. Nenhum instrumento comportamental tem 99,9% de validade. O que se diz ao mercado: "cálculo 100% auditável, instrumento em processo de validação com norma brasileira própria".
